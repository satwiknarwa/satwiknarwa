## 🚀 Projects

### 1. AI-Powered ERP Agent System

A natural-language interface for querying ERP data, combining LLM-assisted Text-to-SQL generation with semantic retrieval and database safeguards.

**Focus areas:** FastAPI, React, LlamaIndex, PostgreSQL/pgvector, SQL validation, prompt-injection defenses, and access-aware query handling.

### 2. Custom Voice Cloning & AI Voice Chatbot *(In Progress)*

A learning project to prepare a single-speaker dataset from personal voice recordings and build a pipeline that connects speech recognition, LLM responses, and a custom text-to-speech model.

**Current focus:** Audio preprocessing, audio-text alignment, and preparing data to adapt an open-source TTS model. The custom model and end-to-end integration are still in development.

🔗 **Code (existing voice chatbot):** [View AI-voicebot repository](https://github.com/satwiknarwa/AI-voicebot) — this repository contains the existing Django-based speech-to-text → LLM → text-to-speech chatbot; the custom voice-training code is still in progress.

### 3. AI Voice Chatbot

A Python/Django-based voice chatbot experiment using speech recognition, an LLM API for responses, and text-to-speech output.

🔗 **Repository:** [AI-voicebot](https://github.com/satwiknarwa/AI-voicebot)
